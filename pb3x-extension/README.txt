PB3X — Plazma Burst 3 client mods (browser extension) 0.0.26.202609261101
=================================================================

New vehicles (TGS helicopter and bike), physics gore, menu themes and glitch effects, chat tools, custom emoji,
an FPS overlay and more, running inside the real game at https://www.plazmaburst.net/.

Mods: Better chat, Bosses, Color Packet Fix, Custom emoji, Custom grenades, Dynamic gore, More vehicles, Performance overlay.

Install (Chrome, Edge, Brave, Opera)
------------------------------------
1. Unzip this somewhere it can stay (the browser loads it from this folder, so don't delete it).
2. Open the extensions page: chrome://extensions (Edge: edge://extensions, Opera: opera://extensions)
   and switch on "Developer mode".
3. Click "Load unpacked" and choose the pb3x-extension folder (the one with manifest.json in it).
4. Open https://www.plazmaburst.net/ (reload it if it was already open).
   * Menu > Mods: every mod starts switched off. Switch on the ones you want and reload.
   * Settings > Customization: themes, effects, glitch effects, UI colours, your own background.

Update: replace the files in this folder with the new version, then press the reload arrow on PB3X
in the extensions page and reload the game.
Remove: press Remove on PB3X in the extensions page.

Good to know
------------
* It only runs on plazmaburst.net. The one other thing it's allowed to do is let the classic menu
  music (Settings > Customization > Music) stream in from khinsider's music hosts, which is why the
  browser lists access to vgmtreasurechest.com and downloads.khinsider.com.
* Maps with the new vehicles need everyone in the match to have PB3X, and a host that has it:
  the official servers don't, so the mod offers to host such a match on your PC.
* If you also have the PB3X userscript in Tampermonkey/Violentmonkey, only one of them runs.
* Fan-made; not affiliated with Plazma Burst 3 or its developer.
